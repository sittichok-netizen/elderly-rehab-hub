เริ่มต้นใช้งาน

HAH Sensory Design System ใช้งานด้วย CSS ไฟล์เดียว ไม่ต้องพึ่ง React, Babel หรือ bundler

1. Import styles

<!-- วางใน <head> — ไฟล์เดียวได้ทุก component --> <link rel="stylesheet" href="/design-system/styles.css">

2. Import behavior layer (optional)

<!-- วางก่อน </body> เพื่อใช้ SensoryUI.drawer / .modal / .toast / .dropdown --> <script src="/design-system/sensory-ui.js"></script>

3. ใช้ component

<!-- ทุก component ใช้ sensory-* prefix --> <button class="sensory-btn is-primary">บันทึก</button> <span class="sensory-badge tone-success">อนุมัติ</span> <div class="sensory-card">...</div>

Cloudflare Pages — path structure

public/ design-system/ styles.css ← @import manifest sensory-ui.js ← behavior layer tokens/ ← CSS token files fonts.css colors.css typography.css spacing.css base.css components.css

SensoryUI.js

Vanilla JS behavior layer — dependency-free, data-attribute driven. auto-init ทุก component ใน DOM เมื่อ DOMContentLoaded

Data attributes (auto-wired)

Attributeใช้กับพฤติกรรม
data-drawer-open="id"buttonเปิด Drawer ที่ id นั้น
data-drawer-close="id"buttonปิด Drawer
data-drawer-scrim="id"scrim divคลิก backdrop ปิด Drawer
data-modal-open="id"buttonเปิด Modal
data-modal-close="id"buttonปิด Modal
data-modal-scrim="id"scrim divคลิก backdrop ปิด Modal
data-sensory-dropdown="id"buttontoggle Dropdown

Programmatic API

SensoryUI.drawer.open('my-drawer', triggerEl) // เปิด drawer + focus trap SensoryUI.drawer.close('my-drawer') // ปิด + return focus to trigger SensoryUI.modal.open('confirm-modal', triggerEl) SensoryUI.modal.close('confirm-modal') SensoryUI.toast('บันทึกแล้ว', { tone: 'success', duration: 3500 }) // tones: 'success' | 'warning' | 'danger' | 'info' SensoryUI.dropdown.toggle('actions-menu', triggerEl) SensoryUI.dropdown.close('actions-menu') SensoryUI.init() // re-wire ทุก component (เรียกหลัง dynamic DOM insert)
