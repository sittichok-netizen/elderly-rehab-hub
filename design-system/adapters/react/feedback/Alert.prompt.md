Inline banner for confirmations, policy notices and warnings inside forms/pages.

```jsx
<Alert tone="success" title="ส่งคำขอแล้ว">หัวหน้างานจะได้รับการแจ้งเตือนเพื่ออนุมัติ</Alert>
<Alert tone="warning">วันลาพักร้อนคงเหลือ 2 วัน</Alert>
```

Tones `info` `success` `warning` `danger` each set the icon and colour. `title` optional.
