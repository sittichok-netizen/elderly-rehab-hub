Icon-only button for toolbars, headers and table-row actions. Always provide `aria-label`.

```jsx
<IconButton aria-label="แก้ไข"><i data-lucide="pencil" /></IconButton>
<IconButton solid size="sm" aria-label="ตัวเลือกเพิ่มเติม"><i data-lucide="more-horizontal" /></IconButton>
```

`solid` gives it a card surface + border; default is transparent ghost. Sizes `sm` / `md` / `lg`.
