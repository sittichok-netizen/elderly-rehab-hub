The base surface for panels, list containers and dashboard widgets.

```jsx
<Card>
  <CardHeader title="คำขอลาล่าสุด" action={<Button variant="ghost" size="sm">ดูทั้งหมด</Button>} />
  <CardBody>…</CardBody>
</Card>
```

`flat` drops the shadow (nested cards); `interactive` lifts on hover for clickable cards.
