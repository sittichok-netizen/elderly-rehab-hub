Status pill for approval / leave / evaluation states. Map tone to meaning consistently.

```jsx
<Badge tone="success" dot>อนุมัติแล้ว</Badge>
<Badge tone="warning" dot>รออนุมัติ</Badge>
<Badge tone="danger" dot>ปฏิเสธ</Badge>
<Badge tone="brand" solid>ใหม่</Badge>
```

Tones: `neutral` `brand` `success` `warning` `danger` `info`. `dot` adds a leading status dot; `solid` fills (brand/success/danger).
